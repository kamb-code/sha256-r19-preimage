**Verdict.** EDGE STAYS HEAVY. No widened condition class weakened the a5 -> C1 edge. ## Plain English

You asked whether any condition on the context words could quietly defuse the one edge that stops a5 from being absorbed at 20 rounds: the Sigma0(a5) sitting inside e6 in W10, which is how a5 reaches the C1 lookup. Five separate searches, using different code paths, attacked it from different directions: every constant you can pin (e8, e9's offset, e10, e11, a6, a7, a4, all the way to 100,000 random values of each and 160,000 random pairs); every rotation, XOR, additive, Sigma0/Sigma1 and GF(2)-linear tie between context words (145,645 conditions); an explicit symbolic hunt for a second occurrence of Sigma0(a5) or Sigma1 that could cancel it; an extended-menu sweep with a full 2^32 scan of the residual's structure; and a reduced-width model that at 5 bits was literally exhaustive over all 2^25 contexts. All of them find the same thing. Once a0..a3 and the context are fixed, the C1 target depends on a5 exactly through four atoms, -Sigma0(a5) - Maj(a5,a4,a3) + Sigma1(a5+c9) + Ch(a5+c9, e8, e7), and the context has only two levers: it can flatten the Maj/Ch terms (worth about 1-2 bits) and it can choose the constant c9 = a9 - T2(a8,a7,a6). The modular difference Sigma1(a5+c9) - Sigma0(a5) never drops below 10.3 bits for any c9 (201,058 values scanned, including every sparse one), and nothing else in the context reaches W10 at all: e10, e11, a10, a11 and the digest words provably leave the a5-difference in T1 bit-identical. So the best you can do is c9 in {0, 2^31} with a7 = a6 = a4 (or ~a4) and e8 = -1, which lands at 10.9-11.0 bits, and the residual is statistically a random 32-bit map: no output bit is affine in a5, the additive difference takes hundreds to thousands of distinct values per flipped bit, and P(residual = 0) is 2 x 2^-32, exactly the random-function value. The consolation finding, reproduced by four of the five explorers, is that a5 can be made exactly absent from C0 (a6 = ~a4, a7 = a6, e8 = -1) and from C2, and exactly linear in C3, so the entire 20-round obstruction really is this single C1 edge and nothing else. That is a clean statement for the barrier note, but it is a statement of where the wall is, not a hole in it. Attacking it further would need something that is not a context condition: a different unknown ordering, or a way to control a9 that does not leak a5 into W17 and sigma1(W15).

## For the record
